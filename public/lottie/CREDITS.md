# Animations

All four files are drawn by our team for StockSense as plain Lottie JSON, so there is no third party license to track.
Colors come from the design tokens: success green, accent blue, grays.

| File | Used by | Plays |
|---|---|---|
| `success.json` | `ValidateSuccess` after a receipt, delivery or adjustment is validated | once: circle draws, check draws, small settle |
| `empty.json` | `EmptyState` on empty lists and searches | loops slowly, flaps sway |
| `bell.json` | `AlertBell` when the low stock count goes up | once: swings and settles |
| `loading.json` | tables that take longer than 600ms to load | loops |

Any file added from LottieFiles later goes in this table with its author, link and license.
